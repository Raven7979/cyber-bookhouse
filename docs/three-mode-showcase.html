蒸馏部分

  • 核心方法：目标校准 → 补足上下文 → 提供工具 → 人在环验证。
  • 反例：只生成一份看起来很厉害的报告，会制造“理解了”的错觉。
  • 失败边界：案例经验不能自动外推为所有场景的稳定规律。
