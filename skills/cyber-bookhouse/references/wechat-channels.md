# 微信视频号与腾讯元宝

视频号分享链接本身通常不足以证明已经取得视频内容。只有真实 MP4、可见字幕
或已授权页面内容到手后，才能写逐字稿和画面结论。

## 可用路线

按下面顺序选择：

1. 用户提供其有权保存的本地 MP4；
2. 当前电脑已经安装并可调用 `download-wechat-channels` Skill 时，使用它的
   腾讯元宝官方链路；
3. 用户从自己有权使用的官方工具导出或录屏后提供本地文件；
4. 仍然拿不到时，只保存链接、标题和访问限制。

公共 `cyber-bookhouse.zip` 不重新打包来源和再分发许可不明确的第三方下载
代码。检测到独立 Skill 不等于真实下载可用；未检测到时也不要从未知在线下载站
临时找解析器。

## 腾讯元宝路线的验收条件

这条路线只适用于 Codex 桌面应用：

1. 从 Plugins Directory 安装官方 Browser；
2. 用户阅读风险后，自行确认启用 Browser 完整 CDP；
3. Browser 打开 `https://yuanbao.tencent.com/`，由用户本人扫码登录；
4. 独立 Skill 的离线自测通过；
5. 用一条用户有权保存的真实视频号链接完成下载，核对 MP4 文件存在且可读；
6. 再按 [media.md](media.md) 本地转写和抽帧。

不要把“脚本存在”“自测通过”“元宝已登录”中的任意一项单独写成“视频号可用”。
没有授权测试链接时，状态只能写“组件已安装，待首个授权视频实测”。

## 安全边界

- 只处理用户自有或已获授权的内容；
- 不绕过私密、付费、已删除内容、验证码、DRM 或访问控制；
- 不读取、导出、打印或复制 Cookie、Local Storage、密码、验证码、Token；
- 不把分享链接或浏览器凭据发送给未知公共解析器；
- 不安装证书、不修改系统代理、不操控微信客户端；
- Browser/CDP 不可用时，直接回到本地 MP4 路线。

Claude Code、WorkBuddy、Codex CLI 和 Codex IDE 扩展不能照搬 Codex 桌面
Browser 流程。除非它们已有经过用户授权和真实验收的等价能力，否则要求用户
提供本地 MP4。
