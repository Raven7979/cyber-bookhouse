# 安装完成后的命令

安装、手机测试和可选入口测试全部通过后，把下面这段直接发给用户：

> 赛博书屋已经安装完成。以后在 WorkBuddy、Codex、Claude、手机端，以及你刚接好
> 的飞书或微信助理中，都可以直接发送下面的命令：
>
> - `同步笔记：https://文章、视频或播客链接`
> - `蒸馏笔记：https://文章、视频或播客链接`
> - `详细拆解：https://文章、视频或播客链接`
> - `检查书屋`
>
> “同步笔记”会做视频总结、逐字稿和必要的翻译，图文则做正文总结，
> 适合学习、记录和留档；“蒸馏笔记”做详细结构分析，重点适合短片拉片；
> “详细拆解”完整包含前两种结果。电脑需要保持在线。
> 当内容里真的存在 SOP、框架、多路分支或短片节奏时，笔记会适当插入
> 流程图、框架图或时间线；普通内容不会为了好看强行配图。

同时报告当前入口和本地书屋路径。不要暴露账号、设备名、会话 ID 或连接凭据。

`收进书屋：URL` 继续作为 `同步笔记：URL` 的兼容说法。
