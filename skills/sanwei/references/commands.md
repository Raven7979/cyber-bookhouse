# 安装完成后的命令

安装、手机测试和可选入口测试全部通过后，把下面这段直接发给用户：

> 赛博三味书屋已经安装完成。以后在 WorkBuddy、Codex、手机端，以及你刚接好
> 的飞书或微信中，都可以直接发送下面的命令：
>
> - `同步笔记：https://文章、视频或播客链接`
> - `蒸馏笔记：https://文章、视频或播客链接`
> - `详细拆解：https://文章、视频或播客链接`
> - `检查书屋`
>
> “同步笔记”适合日常收藏；“蒸馏笔记”只提炼可复用的方法和结论；
> “详细拆解”会同时保留标准笔记、蒸馏结果和内容结构。电脑需要保持在线。

同时报告当前入口和本地书屋路径。不要暴露账号、设备名、会话 ID 或连接凭据。

`收进书屋：URL` 继续作为 `同步笔记：URL` 的兼容说法。
