# 三种笔记模式

根据命令直接选择模式，不再追问。

## 同步笔记

触发词：`同步笔记`、`收进书屋`、`笔记同步`。

写入 `note_mode: standard`，适合学习、记录和留档。

- 视频、播客和音频：简单内容总结 + 有时间点的逐字稿 + 翻译。原文已是
  用户使用的语言时，标注“无需翻译”；语言不同时，保留原文并附上翻译。
- 图文和文档：原链接、正文要点、简单总结、关键事实和待验证项。

只在真实取得媒体、字幕或语音转写时生成逐字稿和翻译。拿不到时保留
已有总结与限制，不用标题和简介补写逐字稿。

## 蒸馏笔记

触发词：`蒸馏笔记`。

写入 `note_mode: distilled`。这是详细的结构分析模式，重点用于短片拉片。

视频中按时间线记录镜头、画面信息、台词或旁白、声音、节奏、转场和情绪，
再分析开场如何抓人、信息如何推进、高潮与结尾如何完成，以及哪些表达可复用、
哪些只在当前素材中成立。图文和文档则分析标题、结构、论据、叙事、表达技巧与
失败边界。

开始前读取 [distillation.md](distillation.md)。视频拉片必须真实取得画面和声音；
只有逐字稿时可以分析语言结构，但不得写镜头、构图、转场或表演结论。

## 详细拆解

触发词：`详细拆解`。

写入 `note_mode: detailed`。完整包含“同步笔记”和“蒸馏笔记”的所有内容：
总结、逐字稿、必要的翻译，以及结构/镜头/表达的详细分析。不要把推断写成
来源事实。

其中的蒸馏部分同样执行 [distillation.md](distillation.md) 的证据门、验证、
边界和压力测试。

三个模式遵守同一条证据边界：拿不到正文、媒体、字幕或转写时，明确标注
`partial`、`metadata_only` 或 `unavailable`，不得补写不存在的内容。

对外只使用“蒸馏笔记”“蒸馏模式”和“蒸馏结果”这组说法。无论最终笔记、
用户回复、命令说明还是处理过程摘要，都不展示内部方法、模板或 Skill 的来源
名称。
